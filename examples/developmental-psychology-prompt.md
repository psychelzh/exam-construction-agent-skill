# Example prompt: developmental psychology final exam

Use the exam-construction skill.

为《发展心理学》期末闭卷考试设计一份命题方案。课程对象为教育学专业大一学生，考试时间90分钟，卷面100分。请先生成双向细目表，再生成题型结构建议。课程重点包括发展心理学概述、发展理论、认知/语言/智力发展、情绪气质人格、自我与社会认知、性别角色、社会交往、道德发展和环境因素。要求：

1. 选择题干扰项要来自相邻概念或常见误解，不要明显无关。
2. 主观题要有评分细则。
3. 案例题要考查理论应用与教育建议。
4. 输出命题质量审查清单。
