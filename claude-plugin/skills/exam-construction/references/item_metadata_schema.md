# Item Metadata Schema

Use this schema when building an item bank or formal exam review table.

| Field | Description | Example |
|---|---|---|
| item_id | Unique item identifier | DP-MCQ-001 |
| item_type | MCQ, short answer, essay, case analysis, etc. | MCQ |
| content_domain | Chapter, lecture, topic, or objective | 发展心理学理论 |
| learning_objective | Specific course outcome | 区分皮亚杰与维果茨基理论 |
| cognitive_level | Recall, understanding, application, analysis, evaluation | Application |
| expected_difficulty | Easy, medium, hard, or expected p-value | Medium |
| score | Points assigned | 2 |
| correct_answer | Correct option or scoring key | A |
| source_basis | Syllabus, lecture slide, textbook, teacher note | 第2讲课件 |
| distractor_rationale | Why each wrong option is plausible but wrong | B: 将社会学习理论与社会文化理论混淆 |
| qa_status | Draft, reviewed, needs revision, approved | Reviewed |
| reviewer_note | Quality-control note | 干扰项C过弱，建议替换 |
