# Post-Exam Item Analysis Guide

Use this guide when student response data are available.

## Data requirements

For objective items:

- Student ID or anonymous respondent ID.
- Student response for each item.
- Answer key.
- Optional: item metadata such as content domain and cognitive level.

For subjective items:

- Item scores.
- Maximum scores.
- Optional rater ID when multiple raters exist.

## Core indices

- Difficulty index p: proportion of students answering correctly.
- Corrected item-total correlation: relation between item score and total score excluding that item.
- High-low discrimination: p in upper group minus p in lower group.
- Distractor frequency: how often each incorrect option was selected.
- Nonresponse rate: missing or blank responses.

## Interpretation rules

- Very easy items may still be useful for core minimal competency.
- Very hard items may be useful only if aligned with advanced objectives and discriminating positively.
- Negative discrimination is a warning sign: check answer key, ambiguity, coverage, and wording.
- Distractors selected by almost no one are nonfunctioning and should be revised or removed.
- A distractor selected frequently by high scorers may indicate ambiguity or a second defensible answer.

## Small-sample caution

For small classes, item statistics are unstable. Treat analysis as diagnostic evidence, not definitive psychometric validation. Combine statistics with qualitative review.
